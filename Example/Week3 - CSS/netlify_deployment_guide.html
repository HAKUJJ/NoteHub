เข้าสู่ระบบและอัปโหลดเว็บ
สู่ Netlify อย่างถูกต้องและถาวร

การนำเว็บไซต์ HTML/CSS ขึ้นโฮสติ้งจริงด้วยการ Login ผ่านบัญชี Netlify ก่อนอัปโหลด (Manual Deploy) เป็นวิธีที่ถูกต้องและปลอดภัยที่สุด ช่วยให้เว็บไซต์ของคุณคงอยู่ถาวร สามารถย้อนกลับมาแก้ไขโค้ด (Re-deploy), ปรับแต่ง Subdomain เป็นชื่อตัวเอง และรวบรวมงานทั้งหมดเป็น Portfolio ส่งอาจารย์ได้อย่างสมบูรณ์แบบ

เว็บผูกกับ Account ถาวร ไม่สูญหาย อัปเดตโค้ดใหม่ได้ตลอดเวลา (URL เดิม) ได้ HTTPS และ SSL Certificate ฟรี

ไปที่หน้า Login ของ Netlify

ช่องทางการ Login เข้าสู่ระบบ Netlify

เลือกช่องทางการเข้าสู่ระบบที่สะดวก เพื่อเป็นเจ้าของเว็บไซต์และจัดการงานทั้งหมดได้ในที่เดียว

แนะนำสูงสุด ⭐

เข้าสู่ระบบด้วย GitHub

สะดวกที่สุดสำหรับสายโปรแกรมเมอร์ เพียงกด "Log in with GitHub" และอนุมัติสิทธิ์ ระบบจะสร้างบัญชีให้ทันที พร้อมต่อยอดเชื่อม Git Repository ในอนาคต

เข้าสู่ระบบด้วย Email

ใช้อีเมล (เช่น อีเมลนักศึกษาหรือ Gmail ส่วนตัว) สมัครผ่าน "Sign up with Email" แล้วยืนยันลิงก์ในกล่องจดหมายเพื่อเริ่มใช้งาน

เข้าสู่ระบบด้วย Google

คลิก "Log in with Google" เพื่อล็อกอินอย่างรวดเร็วโดยไม่ต้องจำรหัสผ่านแยก จัดการสิทธิ์การเข้าถึงผ่านบัญชี Google ส่วนตัวของคุณได้ทันที

ขั้นตอนเตรียมความพร้อม: โครงสร้างโฟลเดอร์โปรเจกต์ (Folder Structure)

หัวใจสำคัญที่สุดก่อนนำเว็บขึ้นโฮสติ้ง หากโครงสร้างผิด ลิงก์ CSS และรูปภาพจะไม่แสดงผล

ตัวอย่างโครงสร้างที่ถูกต้อง (Recommended) Root Level
📁 my-cs319-assignment/ <-- โฟลเดอร์หลักที่จะลากอัปโหลด (Root)
│
├── 📄 index.html <-- ต้องชื่อนี้เท่านั้น! (หน้าแรก)
├── 📄 style.css <-- ไฟล์สไตล์ชีต CSS
└── 📁 images/ <-- โฟลเดอร์เก็บภาพ
    ├── 🖼️ profile.jpg
    └── 🖼️ banner.png

เซิร์ฟเวอร์ของ Netlify จะค้นหาไฟล์ชื่อ index.html ที่ Root Directory เป็นหน้าแรกโดยอัตโนมัติ

3 กฎเหล็กในการอ้างอิงไฟล์ (Path Rules)
  • ห้ามใช้ Absolute Path ในเครื่อง: เช่น C:\Users\Name\img.jpg หรือ D:\project\style.css เพราะเครื่องอื่นจะมองไม่เห็น
  • ใช้ Relative Path เสมอ: เช่น images/profile.jpg หรือ ./style.css
  • ระวัง Case Sensitive: บนเซิร์ฟเวอร์ Linux ชื่อ Photo.JPG กับ photo.jpg คือคนละไฟล์กัน

4 ขั้นตอนการ Login และ Upload เว็บไซต์อย่างละเอียด

ปฏิบัติตามทีละขั้นตอนเพื่อรับ URL เว็บไซต์ที่ผูกกับบัญชีของคุณอย่างถาวร

1

Login เข้าสู่ระบบ

เปิดเบราว์เซอร์ไปที่ app.netlify.com/login แล้วล็อกอินด้วย GitHub หรือ Email ของคุณ

ตรวจสอบว่าเข้าสู่ Dashboard เรียบร้อย
2

ไปที่เมนู Projects & Deploy

คลิกที่เมนู "Projects" ในแถบด้านซ้าย แล้วกดปุ่ม "Add new project" > เลือก "Deploy manually" (หรือเข้า app.netlify.com/drop)

จะปรากฏพื้นที่ Drag & Drop Zone
3

ลากโฟลเดอร์เพื่อ Upload

ลากโฟลเดอร์โปรเจกต์ (ที่มีไฟล์ index.html) จากเครื่องคอมพิวเตอร์ของคุณมาวางลงในกรอบสี่เหลี่ยมเส้นประ

อัปโหลดและสร้างโปรเจกต์ภายในไม่กี่วินาที
4

รับ Live URL ในบัญชี

ระบบจะแสดงสถานะ "Published" พร้อม Live URL (เช่น https://xxxx.netlify.app) ที่บันทึกอยู่ใน Account พร้อมส่งงานทันที

ผูกกับบัญชีคุณถาวร ไม่สูญหาย

การจัดการโปรเจกต์หลัง Login: เปลี่ยนชื่อ Project Name และอัปเดตโค้ด

สิทธิประโยชน์ของการ Login คือการจัดการ Project Name และอัปเดตงานเดิมได้อย่างอิสระ

วิธีเปลี่ยนชื่อโปรเจกต์ให้อ่านง่าย (Custom Project Name / Subdomain)

โดยเริ่มต้น Netlify จะสุ่มชื่อเช่น fluffy-cupcake-12345.netlify.app เราสามารถเปลี่ยนเป็นชื่อตัวเองได้ฟรี:

  1. เข้าสู่หน้าจัดการโปรเจกต์ (Project Overview) บน Netlify Dashboard
  2. กดเมนู Project configuration หรือ Project settings
  3. เลือก Project details > Change Project name
  4. พิมพ์ชื่อที่ต้องการ เช่น cs319-natdanai-w3
  5. กด Save จะได้ URL ใหม่ทันที: cs319-natdanai-w3.netlify.app
วิธีอัปเดตโค้ดเมื่อมีการแก้ไขงาน (Re-deploying)

หากแก้ไขไฟล์ HTML หรือ CSS ในเครื่องแล้วต้องการให้ออนไลน์เปลี่ยนตาม โดยที่ URL เดิมไม่เปลี่ยน:

  1. เข้าสู่โปรเจกต์เดิมบน Netlify Dashboard (ที่ล็อกอินอยู่)
  2. กดที่แท็บ Deploys ในเมนูด้านบน
  3. เลื่อนลงมาด้านล่างจะพบกรอบข้อความ "Need to update your project? Drag and drop your project output folder here"
  4. ลากโฟลเดอร์ใหม่ลงในกรอบ ระบบจะอัปเดตเวอร์ชันใหม่ทันทีโดย URL เดิมไม่เปลี่ยนแปลง!

การแก้ปัญหาที่พบบ่อย (Troubleshooting FAQ)

ตรวจสอบจุดผิดพลาดเหล่านี้หากหน้าเว็บออนไลน์ของคุณแสดงผลไม่ถูกต้อง

ขึ้นหน้า Page Not Found 404

สาเหตุ: ในโฟลเดอร์ไม่มีไฟล์ชื่อ index.html อยู่ที่ Root หรือเผลอลากโฟลเดอร์ซ้อนโฟลเดอร์
วิธีแก้: ตรวจสอบว่าเปิดโฟลเดอร์แล้วเจอ index.html ทันทีหรือไม่

รูปภาพไม่แสดงผล (Broken Image)

สาเหตุ: เขียน path รูปภาพเป็น drive ในเครื่อง (เช่น C:\...) หรือนามสกุลไฟล์พิมพ์เล็ก-ใหญ่ไม่ตรงกัน
วิธีแก้: แก้ path ในแท็ก <img src="images/pic.jpg"> และเช็คนามสกุล .jpg / .png ให้ตรง

CSS ไม่ทำงาน หน้าเว็บไม่มีสีสัน

สาเหตุ: ชื่อไฟล์ใน <link rel="stylesheet" href="..."> ไม่ตรงกับชื่อไฟล์จริง
วิธีแก้: ตรวจสอบแท็ก <link href="style.css" rel="stylesheet"> ให้อยู่ในตำแหน่งที่ถูกต้อง
