0. ทฤษฎีพื้นฐาน: CSS Selectors & Box Model

พื้นฐานที่ต้องรู้ก่อนเริ่มเขียน Cascading Style Sheets

1. Tag Selector

TAG

อ้างอิงตามชื่อแท็ก HTML โดยตรง มีผลกับทุกแท็กชนิดนั้นในทั้งหน้าเว็บ

body, h2, table, button

2. Class Selector

.CLASS

มีจุด . นำหน้า ใช้สร้างสไตล์ซ้ำๆ แปะในแท็กต่างๆ ผ่าน class="..."

.container, .btn-primary

3. ID Selector

#ID

มีเครื่องหมาย # นำหน้า ใช้เจาะจงเฉพาะจุดเดียวในหน้าเว็บที่มี id="..."

#about, #contact-form

📦 CSS Box Model ที่เราจะใช้ในทุก Element:

Margin ระยะห่างภายนอกขอบ
Border เส้นขอบของกล่อง
Padding ระยะห่างภายในขอบ
Content เนื้อหาหรือข้อความ

ขั้นตอนที่ 1: ครอบกล่องโครงสร้างด้วย Class .container

จัดระเบียบเนื้อหาให้อยู่ตรงกลางหน้าจอ ไม่ยืดติดขอบ

เปิดไฟล์ W2 - assignment_2_portfolio_code.html แล้วนำแท็ก <div class="container"> มาครอบเนื้อหาทั้งหมดตั้งแต่ <header> จนถึง <footer>:

HTML Body Structure 
<body>

    <!-- เริ่มต้นครอบ Container -->
    <div class="container">

        <header>...</header>
        <hr>
        <main id="main-content">...</main>
        <footer>...</footer>

        </div> <!-- สิ้นสุด Container -->

</body>
💡 เจาะลึก CSS ของ .container:
  • max-width: 800px; — กำหนดความกว้างสูงสุดไม่ให้หน้าเว็บกว้างเกินไปเมื่อเปิดบนจอคอมขนาดใหญ่
  • margin: 0 auto; — สั่งให้ระยะขอบซ้าย-ขวาคำนวณอัตโนมัติ ทำให้กล่องถูกวางไว้กึ่งกลางหน้าจอเสมอ
  • background-color: #ffffff; — พื้นหลังสีขาวตัดกับสีพื้นหลังเพจ (#f4f6f9)
  • border-radius: 8px; — ปรับขอบมุมกล่องให้มีความโค้งมนสวยงาม

ขั้นตอนที่ 2: กำหนดสไตล์พื้นฐานของแท็ก Body

สร้างแท็ก <style> ภายใน <head> เพื่อตั้งค่าแบบอักษรและสีพื้นหลัง

ไปที่ส่วน <head> ของเอกสาร แล้วเพิ่มแท็ก <style> พร้อมกำหนดสไตล์ของ body:

CSS Body Styles 
/* จัดฟอนต์และพื้นหลังของทั้งหน้าเว็บ */
body {
    font-family: Arial, sans-serif;  /* เปลี่ยนฟอนต์ให้อ่านง่าย */
    background-color: #f4f6f9;       /* สีเทาฟ้าอ่อน สบายตา */
    color: #333333;                  /* สีตัวอักษรเทาเข้ม ชัดเจน */
    margin: 20px;                    /* เว้นขอบรอบนอก */
    line-height: 1.6;                /* ระยะห่างระหว่างบรรทัด */
}

ขั้นตอนที่ 3: ตกแต่ง Header และเมนูนำทาง (Navbar)

แปลงรายการ unordered list (<ul>) ให้เป็นปุ่มกดแนวนอนพร้อม Hover Effect

CSS Header & Nav 
header {
    background-color: #1e3a8a; /* น้ำเงินเข้ม (Primary Theme) */
    color: #ffffff;
    padding: 20px;
    text-align: center;
    border-radius: 6px;
}

header h1 {
    margin-bottom: 5px;
}

    list-style-type: none; /* ซ่อนสัญลักษณ์จุด bullet */
    padding: 0;
    margin-top: 15px;
    text-align: center;
}

nav ul li {
    display: inline-block; /* เรียงเมนูเป็นแนวนอน */
    margin: 0 10px;

    color: #ffffff;
    text-decoration: none; /* ซ่อนเส้นใต้ลิงก์ */

ขั้นตอนที่ 8: ทำ Responsive Web Design ด้วย Media Query (@media)

ปรับแต่งหน้าเว็บให้ย่อขยายพอดีกับจอมือถือ (max-width: 640px)

CSS Media Query for Mobile 
/* 4. RESPONSIVE DESIGN (Media Query) */
@media (max-width: 640px) {
    body {
        margin: 10px;
    }

    .container {
        padding: 15px 12px;
        border-radius: 6px;
    }

    header {
        padding: 15px 10px;
    }

    header h1 {
        font-size: 1.4rem;
    }

    nav ul li {
        display: inline-block;
        margin: 4px 3px;
    }

    nav ul li a {
        display: inline-block;
        font-size: 0.85rem;
        padding: 6px 8px;
    }

    .btn-primary,
    .btn-secondary {
        width: 100%;
        margin-bottom: 8px;
        padding: 10px;
    }
}
